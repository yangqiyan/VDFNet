# Public Benchmark Datasets

This page lists the original release pages of the four public benchmark datasets used in our optical–SAR semantic segmentation experiments.

| Dataset | Original release page |
|---|---|
| Pohang | https://github.com/XD-MG/DDHRNet |
| YESeg-OPT-SAR | https://github.com/yeyuanxin110/YESeg-OPT-SAR |
| DFC2020 | https://ieee-dataport.org/competitions/2020-ieee-grss-data-fusion-contest |
| PIE-RGB-SAR | https://github.com/whu-pzhang/ASANet |

The datasets are provided by their original authors. Please refer to the linked pages for download instructions and dataset citations.
